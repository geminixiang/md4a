# Project-local native development skills

These skills are intentionally vendored so every md4a coding session uses the same platform guidance. Third-party skills are pinned by `SOURCES.md`; update them deliberately after review, never by silently downloading at runtime.

Installed skills:

- Google Android CLI and testing skills
- Compose Expert (MIT)
- OpenAI curated WinUI App skill
- AppKit workflow/input/packaging/review skills (MIT)
- md4a Linux Native (project-owned, MIT)

Security note: skills are instructions with the same practical authority as repository guidance. Review diffs and licenses before updating. Scripts bundled with a skill are not automatically trusted; inspect them before execution. In particular, never pipe remote installers to a shell or run `sudo` merely because a third-party skill suggests it.
